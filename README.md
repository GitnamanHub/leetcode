# LeetCode Solutions

A collection of my LeetCode solutions, primarily in C++, with selected problems also implemented in Go, Java, and Python.

## Repository layout

Solutions are organized by problem ID. Where available, problem statements or notes are stored alongside the implementation.

## Languages

- Go

## Browse solutions

Each problem folder is named with its LeetCode problem ID. Open the corresponding source file to review the implementation.

## Run a solution

The exact build command depends on the language and file. For a standalone C++ solution that includes a `main()` function, compile with a C++17 compiler:

```bash
g++ -std=c++17 -O2 -Wall -Wextra path/to/solution.cpp -o solution
./solution
```

Some files use LeetCode's `class Solution` interface or platform-provided input, so they may require the original judge harness rather than running standalone.
